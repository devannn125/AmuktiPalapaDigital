# Landing Page PT Amukti Palapa Digital

Landing page modern, elegan, berkinerja tinggi dan bebas dari kesan generic "AI slop" untuk **PT Amukti Palapa Digital** (Yogyakarta). Dibangun dengan arsitektur modular menggunakan **React + Vite**, styling **Tailwind CSS**, dan komponen berstandar **shadcn/ui**.

---

1. **Profil & Nilai Perusahaan (BAB I & II)**:

   - Menghadirkan ekosistem teknologi yang menggabungkan inovasi, strategi, dan keahlian digital agar sistem klien *lebih cepat, lebih cerdas, dan lebih efektif*.

## 🚀 Fitur Unggulan Landing Page

- **Clean & Sophisticated Design System**: Palet warna Deep Slate (`#0A1128`), Midnight Navy, Electric Cyan (`#00B4D8`), dan Gold Accent.
- **shadcn/ui Component Architecture**: Button, Card, Badge, Tabs, Accordion, Separator, Dialog Modal.
- **Live Interactive Architecture Mesh Telemetry**: Simulasi status node server, ping latency, dan SLA target.
- **Interactive Project Scope & Sprint Calculator**: Fitur kalkulator interaktif untuk menghitung durasi sprint, perkiraan personil tim, serta opsi add-on teknis.
- **Academic Partnership Showcase**: Bagian terdedikasi untuk program magang 6 bulan dan kolaborasi kampus.
- **Interactive Google Maps Hub**: Penampil rute dan visualisasi lokasi kantor di Sleman / Prambanan.
- **Quick Discovery Modal & WhatsApp Direct Link**: Sarana konsultasi instan yang responsif.

## 🛠 Panduan Menjalankan Proyek

```bash
# Masuk ke direktori
cd landingPage

# Jalankan server pengembangan (Dev Mode)
npm run dev

# Bangun versi produksi (Build)
npm run build

# Pratinjau hasil build (Preview)
npm run preview
```
